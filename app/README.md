# vitrine_plus (código do app)

Código-fonte Flutter do **Vitrine+**. A documentação completa do projeto
(problema, modelo ER, wireframes, arquitetura, como gerar o APK) está no
[README da raiz](../README.md).

```bash
flutter pub get
dart run build_runner build   # gera *.g.dart / *.freezed.dart
flutter test
flutter run
```
